# backlink-copywriter

An explicitly invoked Codex skill for drafting contextual backlink comments and forum replies.

## Contents

- `SKILL.md`: scope, inputs, drafting workflow, and copy QA rules.
- `references/output-contract.md`: structured output contract for downstream review or submission workflows.
- `agents/openai.yaml`: Codex UI metadata and explicit-only invocation policy.

This repository contains copy-generation guidance only. Site qualification, submission, rel verification, tracking, and campaign-level link distribution belong to separate workflows.

Invoke it explicitly with `$backlink-copywriter`.
